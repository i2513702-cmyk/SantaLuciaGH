Imágenes de productos

Cada producto tiene su propia imagen, que se sube desde el formulario de Productos → Nuevo / Editar. Las imágenes viven en el bucket público productos de Supabase Storage y se muestran en la tienda y en los destacados del inicio.

Gestionar productos

Requisito de la base de datos

La tabla productos necesita la columna imagen_url. Si al subir una imagen ves un aviso, ejecuta una vez en el SQL Editor de Supabase: 

ALTER TABLE public.productos
ADD COLUMN IF NOT EXISTS imagen_url text;
